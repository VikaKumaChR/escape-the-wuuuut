# Twisted Space — 시차 관측실: 데모 가이드

🌐 [English](../en/twisted-space-demo-guide.md) · **한국어** · [中文原文](../../Assets/TwistedSpace/Demo/DEMO_GUIDE.txt)

> [!NOTE]
> 이 문서는 초기 **Twisted Space** 플레이 가능 프로토타입을 설명하는 `Assets/TwistedSpace/Demo/DEMO_GUIDE.txt`의 번역입니다.
> 현재 메인 씬에서는 이 방이 **비활성화**되어 있고 XR Device Simulator도 꺼져 있습니다.
> 지금 플레이하는 게임(DepthLab)은 **[플레이 방법](how-to-play.md)**을 참고하세요.

## 열기와 실행

- 씬: `Assets/TwistedSpace/Demo/Scenes/ParallaxChamber.unity`
- Project 창에서 씬을 더블클릭하고, 컴파일이 끝나면 **Play**를 누른 뒤 **Game** 창 안을 클릭합니다.
- 새 파일이 아직 보이지 않으면 **Assets › Refresh**를 사용하세요.
- 수동으로 연결할 것은 없습니다. 씬에 카메라, 머리 감지체, 목표, UI, 모든 버튼 이벤트가 이미 저장되어 있습니다.
- 기존 `Assets/Scenes/SampleScene.unity`는 수정하지 않았습니다.
- 전체 프리팹: `Assets/TwistedSpace/Demo/Prefabs/ParallaxChamber.prefab`. 연결이 끝난 방, UI, XR Rig, 퍼즐이 들어 있어 빈 씬에 바로 넣을 수 있습니다. 다른 XR Rig와 함께 사용하지 마세요.
- 체험 씬은 이 프리팹의 인스턴스를 사용하며, 모든 오브젝트를 펼쳐 확인할 수 있습니다.

참고 사항:

- 에디터는 **Unity 6000.6.8f1**, XRI는 **3.3.2**로 고정되어 있습니다.
- 키보드·마우스 **XR Device Simulator** 체험판이며, 특정 헤드셋용으로 설정된 빌드가 아닙니다.
- SteamVR, 레거시 Input Manager, DOTween, 실시간 배경 블러, Bloom은 추가하지 않았습니다.

## 처음 조작하기

1. **키보드·마우스(Mac 또는 PC):** Play를 누른 뒤 Game 창을 클릭하고, 마우스로 **탐험 시작**을 클릭합니다.
   짧게 클릭해도 진입할 수 있습니다. 0.15초의 확인 지연이 있으며, 시뮬레이션 컨트롤러를 먼저 조준할 필요는 없습니다.
   메인 메뉴는 월드 공간에 고정되어 머리를 따라오지 않습니다. 메뉴가 열려 있는 동안에는 시뮬레이터의 키보드·마우스 조작이 멈추고, 장면의 가림 오브젝트가 숨겨집니다.
   실제 헤드셋에서는 XR 레이와 트리거로 조작하며, 카메라가 마우스 시점에 고정되지 않습니다.
2. 탐험을 시작하면 **Y**로 오른손을 선택하고, **R**로 마우스의 이동/회전 모드를 전환합니다.
   이때 **마우스 왼쪽 버튼**은 선택한 컨트롤러의 트리거입니다. 최소 0.15초 누른 뒤 버튼 위에서 놓아야 확정됩니다.
   빠르게 클릭하거나, 누른 채로 버튼 밖으로 나가거나, 패널이 사라지면 실행되지 않습니다.
3. 잡기는 마우스 왼쪽 버튼이 아니라 **G**(그립)입니다. 손을 프레임의 **단단한 테두리**로 옮긴 뒤 G를 누른 채 손을 움직이고, G를 놓아 내려놓습니다.
   프레임 가운데의 빈 공간은 잡을 수 없습니다.
4. 세 프레임을 차례로 옮긴 뒤 바닥의 **청록색 사각형 관측 구역**으로 돌아갑니다.
   출구를 바라보며 세 프레임의 바깥 윤곽을 겹치고, 약 **0.35초** 유지합니다.
5. 성공하면 프레임이 밝아지고, 슬라이딩 출구 문이 열리며, 소요 시간과 힌트 사용 횟수가 표시됩니다.
   **다시 도전** 또는 **메인 메뉴로 돌아가기**를 선택하세요.

## 공식 시뮬레이터 기본 키 설정(Input System)

| 키 | 동작 |
|---|---|
| **T** / **Y** / **U** | 왼손 / 오른손 / 몸 전체 조작 |
| **Tab** | 조작 대상 순환 |
| **R** | 마우스 이동 / 회전 전환(**왼쪽 Ctrl**을 누르고 있으면 임시 회전 모드) |
| **W A S D** | 현재 장치를 앞 / 왼쪽 / 뒤 / 오른쪽으로 이동 |
| **Q / E** | 현재 장치를 아래 / 위로 이동 |
| **마우스 오른쪽 버튼 유지** | 머리 조작 |
| **마우스 왼쪽 버튼** | 현재 컨트롤러의 트리거 |
| **G** | 현재 컨트롤러의 그립(잡기) |
| **백슬래시(\\)** | 마우스 잠금 전환 |

- 시뮬레이터 두 개를 동시에 켜지 말고, `InputSystemUIInputModule`이나 `StandaloneInputModule`을 추가하지 마세요.
- 키 설정을 바꿀 때는 `Assets/Samples/XR Interaction Toolkit/3.3.2/XR Device Simulator`의 `.inputactions` 에셋 세 개가 기준입니다.

## 시뮬레이터 몸체 충돌

- 전체 프리팹에는 XR Origin 바깥에 **Simulator Collision**이 포함되어 있습니다.
- **U**로 몸을 선택하고 WASD로 이동하면, 캡슐 스윕이 벽, 구조 기둥, 닫힌 문, 바닥, 천장을 막습니다.
- 벽에 비스듬히 부딪히면 벽을 따라 미끄러집니다. 문이 완전히 열리면 출구 공간으로 들어갈 수 있으며, 그 뒤에도 단단한 벽이 있습니다.
- **Q / E**는 디버그용 상하 이동으로 남아 있지만 바닥이나 천장을 통과할 수 없습니다. 중력이나 계단 이동 시스템은 아닙니다.
- 환경 고체는 물리 레이어 **8: TwistedSpaceSolid**를 사용합니다. 관측 구역, 손, 잡을 수 있는 프레임은 이 레이어에 속하지 않습니다.
- 몸 크기와 환경 레이어는 *프리팹 루트 › Simulator Collision*에서 조정합니다.
- 이 컴포넌트는 시뮬레이션 헤드셋이 속한 XR Origin만 보정하며, 카메라의 추적 자세에는 쓰지 않습니다.
- 실제 헤드셋이 연결되었거나 추적 소스가 불분명하면 자동으로 보정을 멈춥니다. 실제 VR에는 별도의 이동 방식과 편의(시야 가림) 대책이 필요합니다.
- 이 수정은 잡은 물체의 키네마틱 이동 방식을 바꾸지 않으며, 손이나 잡은 물체가 벽을 통과하지 않는다고 보장하지 않습니다.

## 게임 플레이와 조작감

- 목표는 서로 독립적이고 중력이 없는 프레임 세 개입니다. 입문 레벨에서는 손목 회전 없이 잡은 **위치**만 따라가며, 놓을 때 던지지 않아 방금 맞춘 실루엣이 계속 흘러가지 않습니다. 이후 `XRGrabInteractable`에서 회전을 켤 수 있습니다.
- 직접 잡으려면 손이 프레임에 닿아야 합니다. UI 레이는 원거리 잡기를 겸하지 않습니다.
- 시뮬레이터에서는 손을 먼 프레임까지 옮기거나, **U**로 몸을 움직였다가 관측 구역으로 돌아올 수 있습니다.
- 겹침 임계값은 **0.65**, 머리 방향 허용 오차는 **25°**입니다.
- **정렬 진행도**는 원래 기하학적 겹침 비율이 아니라 성공 임계값을 기준으로 정규화한 값입니다.
- **안정화 확인**은 임계값에 도달한 뒤 얼마나 유지했는지를 따로 보여 줍니다.
- 전용 머리 콜라이더가 관측 구역 안에 있을 때만 판정합니다. 손이나 소품이 들어가도 작동하지 않습니다.
- 초기화 확인 패널은 판정과 타이머를 멈추지만, 헤드셋 추적을 멈추거나 손을 끌어당기지는 않습니다.
- 물체를 아직 잡고 있으면 초기화할 때 먼저 손을 놓으라고 안내하며, XRI 분리가 끝난 뒤 처음 위치로 복귀합니다.
- 초기화를 취소하면 현재 위치와 타이머가 유지됩니다. 메인 메뉴로 돌아가면 이번 판정이 멈추고, 다시 시작하면 초기화됩니다.
- 결과 화면에서도 퍼즐 컴포넌트는 켜진 상태로 남아 성공 발광 애니메이션이 끝까지 재생됩니다.

## 비주얼과 임시 에셋

- 네 패널은 모두 World Space UGUI입니다: 메인 메뉴, 힌트/진행도, 초기화 확인, 결과.
- 메인 메뉴, 초기화, 결과 패널은 열릴 때 한 번 배치된 뒤 머리를 따라오지 않습니다. 힌트 패널은 퍼즐 오른쪽에 고정됩니다.
- 메인 메뉴는 전용 건축 키 아트, 큰 제목, 분명한 주 버튼을 사용하며, 프레임과 손 모델이 오프닝 화면을 가리지 않습니다.
- 메인 메뉴의 World Space Canvas에는 일반 마우스용 `GraphicRaycaster`와 XR용 `TrackedDeviceGraphicRaycaster`가 함께 있으며, 하나의 `XRUIInputModule`이 입력을 전환합니다. Screen Space Overlay나 두 번째 입력 모듈은 사용하지 않습니다.
- 정적인 중간 굵기의 CJK 폰트, 작은 무광 노이즈 텍스처, 연한 파란색 테두리, 경고용의 약간의 주황색을 사용합니다.
- 시뮬레이터 자체의 화면 오버레이 도움말은 꺼져 있으며, 조작 안내는 씬 안의 떠 있는 안내판으로 제공합니다.
- 오리지널 건축·UI 텍스처, 버튼, 아이콘: `Assets/TwistedSpace/Demo/Art`.
- 방에는 홈이 파인 벽 패널, 분할된 천장 패널, 매입형 조명 띠, 바닥 이음매, 관측 링이 추가되어 있습니다.
- 머티리얼은 작은 텍스처와 적당한 발광을 사용하고, 추가 보조광은 그림자를 만들지 않습니다. 실시간 반투명 유리 블러나 포스트 프로세싱 글로우는 없습니다.
- 변경 사항은 기존 `ParallaxChamber.prefab`에 저장되어 있으므로 복사본을 다시 넣을 필요가 없습니다.
- Play Mode 중이라면 먼저 종료한 뒤 **Assets › Refresh**를 실행하고, 임포트가 끝나면 다시 Play를 누르세요.
- Game 창의 **Scale은 1x**를 권장합니다. 2x는 에디터 화면을 확대할 뿐 게임 해상도를 높이지 않습니다.

임시 에셋:

- 캐릭터는 교체 가능한 임시 오브젝트입니다: 컨트롤러의 장갑, 오른쪽에 떠 있는 보정용 오브젝트, 멀리 있는 관찰자.
- 씬은 편집 가능한 기본 도형으로 만들어졌습니다. 최종 아트, 완성된 스토리, 완전한 레벨 모음이 아닙니다.
- 머티리얼 에셋에는 적당한 Emission이 켜져 있습니다. 빌드에서 발광 배리언트가 제거되지 않도록 키워드를 유지하세요.

## 편집과 확장

| 항목 | 위치 |
|---|---|
| 런타임 컨트롤러 | *Parallax Chamber › Demo Flow* |
| 퍼즐 파라미터 | *Parallax Chamber › Forced Perspective Puzzle* |
| 씬 오브젝트 | *Parallax Chamber › Demo Environment* |
| 패널과 버튼 | *Parallax Chamber › World Space UI* |
| 문 애니메이션 | *Parallax Chamber › Exit Door Controller* |

- 기존 씬을 직접 드래그해 수정하면 됩니다. **Twisted Space › 3. Create Playable Demo Scene**은 씬이 이미 있으면 *열기만* 하고 수정 내용을 덮어쓰지 않습니다.
- 씬 생성기는 원래 구성 과정을 보존하므로, 나중에 별도 복사본에서 확장하기 좋습니다.
- **Twisted Space › Apply Visual And Collision Upgrade**는 이번 업그레이드를 다시 적용하고 프리팹만 저장하며, 씬을 다시 열지 않습니다. 이 메뉴가 담당하는 아트 머티리얼과 장식이 초기화되므로 직접 조정한 값은 먼저 백업하세요.
- 이번 업데이트에서는 기존 렌더 파이프라인 에셋, Build Settings, 실제 헤드셋 Provider 설정을 변경하지 않았습니다.

## 설계용 참고 해답(디버그용)

머리가 `(0, 1.6, 0)`에서 **+Z**를 바라보고, 세 목표가 초기 스케일과 회전 0을 유지할 때, 중심을 각각 `(0, 1.6, 1.55)`, `(0, 1.6, 1.90)`, `(0, 1.6, 2.25)`에 두면 완전히 정렬됩니다.
이 알고리즘은 투영 바운딩 박스의 겹침을 계산하며, 정밀한 픽셀 실루엣 인식이나 자유 형태 퍼즐이 아닙니다.
