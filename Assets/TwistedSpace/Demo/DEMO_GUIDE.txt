逃离扭曲空间：视差观测室（可运行原型）
====================================

打开与运行
----------
场景：Assets/TwistedSpace/Demo/Scenes/ParallaxChamber.unity
在 Unity Project 窗口双击场景，等编译完成后按 Play，再点击 Game 窗口。
如果新文件暂未显示，使用 Assets > Refresh。
不需要重新手动接线；场景中已经保存相机、头部检测体、目标、UI 和所有按钮事件。
原来的 Assets/Scenes/SampleScene.unity 没有被修改。
完整预制体：Assets/TwistedSpace/Demo/Prefabs/ParallaxChamber.prefab。
它包含已接线的房间、UI、XR Rig 和谜题，可拖入空场景；不要与另一个 XR Rig 同时使用。
试玩场景使用该预制体实例，所有物体可展开查看。

此项目实际编辑器为 Unity 6000.6.8f1，XRI 固定为 3.3.2。
这是键鼠 XR Device Simulator 试玩，不是已经配置好的具体头显平台构建。
没有添加 SteamVR、旧版 Input Manager、DOTween、实时背景模糊或 Bloom。

第一次操作
----------
1. Mac 键鼠试玩：Play 后点击 Game 窗口，直接用鼠标点击“开始探索”。
   普通短点击也可进入；点击后有 0.15 秒确认延迟，不需要先瞄准模拟手柄。
   主菜单固定在世界空间，不追着头部移动；菜单期间暂停模拟器键鼠控制并隐藏场景遮挡。
   接真实头显时保留 XR 射线与扳机操作，不把相机当作鼠标视角锁定。
2. 进入探索后按 Y 选择右手，用 R 切换鼠标平移 / 旋转模式。
   此时左键是所选手柄的扳机：按住至少 0.15 秒，在按钮上松开，才会确认。
   快速点击、按住时移出按钮或面板淡出，不会触发。
3. 抓取使用 G（握柄），不是左键。把手移动到框体的一条实体边上，
   按住 G 后移动手，再松开 G 放置。框体中间的空洞不能抓取。
4. 依次移动三个框体，最后回到地面青色方框的观测区。
   面向出口，把三个框体的外轮廓重合，保持约 0.35 秒。
5. 成功后框体变亮、出口滑门打开，显示用时和提示次数。
   可选择“重新挑战”或“返回主菜单”。

官方模拟器默认绑定（Input System）
--------------------------------
T：切换左手操作；Y：切换右手操作；U：切换身体整体操作。
Tab：循环切换操作目标。
R：切换鼠标平移 / 旋转；按住左 Ctrl：临时旋转模式。
W / A / S / D：前后左右平移当前设备。
Q / E：向下 / 向上平移当前设备。
按住鼠标右键：操作头部；鼠标左键：当前控制器扳机。
G：当前控制器握柄（抓取）。
反斜杠：切换鼠标锁定状态。
不要同时开启两个模拟器；不要添加 InputSystemUIInputModule 或 StandaloneInputModule。
如果修改绑定，以 Assets/Samples/XR Interaction Toolkit/3.3.2/XR Device Simulator
中的三个 .inputactions 资源为准。

模拟器身体碰撞
--------------
完整预制体已接入 Simulator Collision，位于 XR Origin 之外。
用 U 切换身体、WASD 移动时，胶囊扫描会阻挡墙壁、结构柱、关闭的门、地板和天花板。
斜向撞墙时沿墙滑动；门完全打开后可进入出口凹室，后方仍有实体墙。
Q / E 保留上下调试移动，但不能穿过地板或顶板；这不是重力或楼梯移动系统。
环境实体使用物理层 8：TwistedSpaceSolid。观测区、手和可抓取框体不在该层中。
调整身体尺寸与环境层：预制体根节点 / Simulator Collision。
此组件只修正模拟头显所属 XR Origin，不写入相机的追踪姿态。
连接真实头显或追踪来源不明确时自动停止修正；真实 VR 仍需单独的移动和舒适遮挡方案。
本次修复不改变抓取物体的 Kinematic 移动方式，也不保证手或被握持物体不会穿墙。

玩法和手感
----------
目标是三个独立、无重力的框体。入门关卡只跟随抓取位置、不跟随腕部旋转，
松手不抛掷，避免刚调整好的轮廓继续漂移。后续可在 XRGrabInteractable 中打开旋转。
直接抓取需要手碰到框体；UI 射线不兼任远程抓取。
使用模拟器时可以把手移动到较远框体，或用 U 移动身体后返回观测区。

重合阈值为 0.65，头部方向容差为 25 度。
“对齐进度”是相对于成功阈值归一化的进度，不是原始几何重合率。
“稳定确认”独立表示达到阈值后持续保持的时间。
只能在头部专用碰撞体进入观测区时判定；手和道具进入不会触发。

重置确认面板暂停检测与计时，但不会停止头显追踪或强行拖动手。
如果物体仍被握住，重置会提示先松手；XRI 分离完成后再恢复初始位置。
取消重置保留当前物体位置和计时；返回主菜单停止本轮检测，重新开始会复位。
结算时谜题组件保持启用，让成功发光动画正常结束。

视觉与占位资源
--------------
四种面板都是 World Space UGUI：主菜单、提示/进度、重置确认、结算。
主菜单、重置和结算面板在打开时放置一次，之后不跟随头部；提示固定在谜题右侧。
主菜单采用独立建筑主题底图、大标题与清晰主按钮，几何框体和手部模型不会挡住开场。
主菜单的世界空间 Canvas 同时配置普通鼠标 GraphicRaycaster 和 XR TrackedDeviceGraphicRaycaster，
由同一个 XRUIInputModule 切换输入，不使用 Screen Space Overlay 或第二个输入模块。
使用静态中等字重中文字体、磨砂噪声小纹理、淡蓝边框和少量橙色警告。
模拟器自带的屏幕 Overlay 帮助界面已禁用，操作说明为场景内悬浮牌。
原创建筑与 UI 纹理、按钮和图标：Assets/TwistedSpace/Demo/Art。
房间已增加凹槽墙板、分段顶板、嵌入式灯带、地面接缝和观测环。
材质使用小型纹理与适度自发光，额外补光不投射阴影；没有实时毛玻璃模糊或后期辉光。
更新已保存到原有 ParallaxChamber.prefab，不需要重新拖入另一个副本。
如正在 Play，先退出，再使用 Assets > Refresh，等待导入后重新 Play。
Game 窗口的 Scale 建议设为 1x；2x 是编辑器画面的放大，不是提高游戏分辨率。

角色是可替换占位体：控制器上的手套、右侧悬浮校准体、远处观测者。
场景由可编辑基础几何构成；它不是最终美术模型、完整剧情或完整关卡合集。
材质资源已启用适度 Emission；保持关键字，避免构建时剥离发光变体。

场景生成器保留原始搭建过程，方便以后在独立副本中扩展。
菜单 Twisted Space > Apply Visual And Collision Upgrade 可重新应用本次升级，
只保存该预制体，不会主动重开场景；会重设本次负责的美术材质和装饰，请先备份自定义调整。
本次没有修改原有渲染管线资产、Build Settings 或真实头显 Provider 配置。

设计用参考解（调试时查看）
------------------------
头部位于 (0, 1.6, 0) 并面向 +Z，三个目标保持初始缩放与零旋转，
将中心依次放在 (0,1.6,1.55)、(0,1.6,1.90)、(0,1.6,2.25) 即可完全对齐。
此算法计算投影包围盒重合，不是精确像素轮廓识别或任意形状拼图。
